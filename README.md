# Buzdolabı Işığı Yargılama Dairesi

Resmi ad: **Kapı Açılınca Var Olan Şeyler Genel Müdürlüğü, Işık Şubesi**

Bu depo, insanlığın çözemediği tek anayasal krizi çözer: buzdolabı ışığı kapı kapalıyken de yanıyor mu, yoksa sadece tanık varsa mı var?

Cevap hukuki. Cevap da saçma. İkisi aynı dosyada.

## Yetki

Daire, 5 Ekim 2026 sabahı, kimsenin sormadığı bir anda kuruldu. Kuruluş gerekçesi: "bir şeyler oluyordu, biz de tutanak tuttuk."

## Çalıştırma

```bash
python3 durusma.py
```

Python 3 yeter. Bağımlılık yok. Buzdolabı da yok. Işık zaten şüpheli.

Argümanlar:

```bash
python3 durusma.py --kapi acik --tanik kedi
python3 durusma.py --kapi kapali --tanik yok
```

## Usul

1. Kapı durumu alınır.
2. Tanık dinlenir. Tanık kedi ise beyanı miyav olarak zapta geçer, tercüme edilmez.
3. Işık, gıyaben sanık sıfatıyla dinlenir. Susma hakkını kullanır. Her zaman.
4. Hüküm, milisaniye cinsinden gerekçeli karar olarak basılır.
5. Karar kesin değildir. İstinaf mercii mutfak tezgahıdır.

## Bilinen hata

Kapıyı açıp bakarsanız delil değişir. Buna "gözlemci etkisi" değil, "merak suçu" denir.

## Lisans

Işık serbesttir. Kapı değildir. Ayrıntı `LISANS` dosyasında, okunmayacak şekilde.
